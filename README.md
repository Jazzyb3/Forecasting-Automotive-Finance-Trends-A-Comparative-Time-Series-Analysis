# Forecasting-Automotive-Finance-Trends-A-Comparative-Time-Series-Analysis
Time series forecasting of U.S. auto loan rates using quarterly FRED data. Compares ARIMA(2,1,0), a Multi-Layer Perceptron neural network, and an ensemble model, with stationarity testing, unit root tests, and rolling window RMSE evaluation. MLP outperformed ARIMA, informing auto finance rate forecasting strategy.
